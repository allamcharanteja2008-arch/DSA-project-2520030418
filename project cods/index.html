Complexity

Z-Algorithm

Builds a Z-array over Pattern + $ + Text, reusing the [L, R) window so no character is compared again after it is covered. A Z-value equal to the pattern length marks a match.

Linear-time matching

O(n + m)

Naïve algorithm

Checks the pattern at every possible starting position and restarts after every mismatch.

Worst case, e.g. text AAAA…A and pattern AAA…B

O(nm)

What n and m mean

n is the length of the text. m is the length of the pattern. Z works on a string of length n + m + 1, which is why its cost is written O(n + m).

Pseudocode

Z-Algorithm

function ZSearch(P, T):
    S = P + "$" + T
    n = length(S); m = length(P)
    Z[0..n-1] = 0; L = 0; R = 0
    for i = 1 to n-1:
        if i < R:
            Z[i] = min(R - i, Z[i - L])
        while i + Z[i] < n and S[Z[i]] == S[i + Z[i]]:
            Z[i] = Z[i] + 1
        if i + Z[i] > R:
            L = i; R = i + Z[i]
        if Z[i] == m:
            report match at i - m - 1

Naïve matching

function NaiveSearch(P, T):
    n = length(T); m = length(P)
    for i = 0 to n - m:
        j = 0
        while j < m and T[i + j] == P[j]:
            j = j + 1
        if j == m:
            report match at i

# Efficient String Pattern Matching Using the Z-Algorithm
A Comparative Performance Analysis (Data Structures and Algorithms - 3, 25CS2103E, 2026-2027)

## Run in VS Code
1. Unzip the folder and open it in VS Code (File > Open Folder).
2. Install the "Live Server" extension (Ritwick Dey).
3. Right-click index.html and choose "Open with Live Server".

You can also double-click index.html to open it in any browser. No installation or backend is needed.

## Datasets
The Datasets section of the page can generate DNA, English-like, binary and worst-case repetitive data (fixed seed, so results repeat), or load your own .txt/.csv file.
Ready-made 10,000-character samples are in the datasets/ folder. Choose "Upload your own file" and use these patterns:
- dna_10000.txt: GATTACAGATTACA
- english_10000.txt: pattern matching
- binary_10000.txt: 1011010
- server_logs.csv: connection timeout (CSV of 1,500 synthetic server-log rows: id, timestamp, level, service, message; try also ERROR,gateway or database unavailable)
- worst_case_10000.txt: AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAB (49 A's then B)

## Files
- index.html - page structure
- style.css - dark glassmorphism theme
- script.js - Z-Algorithm, Naive algorithm, visualizers, charts, dataset benchmark
- datasets/ - sample data files
